スクショや写真をブログ・SNS・社内チャットに載せるとき、「あとから気づいたら氏名やメールアドレスが写っていた」「背景に別の人の顔が入っていた」という経験はありませんか。

画像編集ソフトで矩形マスクするのは確実ですが、毎回手作業は面倒で、公開が後回しになったり、うっかりそのまま上げてしまったりしがちです。

![伏せ太郎ヒーローイメージ](https://fusely-app.pages.dev/hero.png)

個人開発で **[伏せ太郎（Fusely）](https://fusely-app.pages.dev/)** を作りました。ブラウザだけで顔や文字を検出し、マスキングしてから画像を書き出せる Web アプリです。

- サービス紹介（LP）: https://fusely-app.pages.dev/lp
- ソースコード: https://github.com/illionillion/privacy-masking-app

## 伏せ太郎でできること

**伏せ太郎**は、画像内の顔やテキスト情報を検出し、公開前にマスキング編集できるブラウザ完結型のツールです。

- ブラウザだけで処理し、**画像データをサーバーへ送信しません**
- 顔検出と OCR で、個人情報の候補を検出します
- 黒塗り・モザイク・ぼかしなどのマスキング編集に対応します
- 編集後の画像をそのままダウンロードできます

完全無料・ログイン不要です。URL を開いて画像を選ぶだけで使えます。

### こんな感じでマスキングできます

画像を選択すると、顔・文字を検出してマスキングできます。検出できない部分は手動で調整・追加も可能です。

| 例 | できること |
| --- | --- |
| 集合写真 | 複数人の顔を一括検出してマスキング |
| 名刺 | 電話番号・メールアドレスなどの文字情報を黒塗り |
| トーク画面 | 投稿された顔写真とメッセージ内の個人情報を同時にマスキング |

### たった3ステップで完了

操作は直感的で、難しい設定は不要です。

1. **画像をドラッグ＆ドロップ** — 対応形式は JPEG・PNG・WebP・GIF。ファイルをブラウザにドロップするだけで読み込み完了。
2. **自動または手動でマスク処理** — 顔・文字を検出してマスキング範囲を提案。検出できない部分は手動で調整・追加できます。
3. **マスク済み画像をダウンロード** — 処理が完了したらボタン1つでダウンロード。元の画像ファイルには手を加えません。

### プライバシーを最優先に設計

大切な画像データは、あなたのデバイスから出ないことを前提にしています。

- **画像はサーバーに送信されない** — アップロードした画像データは一切外部に送信されません。すべての処理はブラウザ内のみで実行されます。
- **すべてブラウザ内で処理** — 顔検出・OCR・マスキングはデバイス上の JavaScript で完結します（ページ表示や初回モデル取得など、通信が必要な場合を除く）。
- **ログイン不要・登録不要** — 会員登録やインストールは不要です。

### こんな場面で使われています

- **SNS 投稿前の画像編集** — インスタグラムや X への投稿前に、写り込んだ顔や個人情報をサッとマスキング。スマホのブラウザからも使えます。
- **社内資料・スクショの共有** — メール・電話番号などを隠してから社外共有。情報漏洩リスクを下げたいときに。
- **イベント・オフ会写真の加工** — 同意を得ていない参加者の顔をマスキングしてから公開。プライバシーに配慮したレポートづくりに。

## 他のやり方との違い

「正解のツール」というより、自分が困っていた場面で選びやすいかどうかの話です。

| やり方 | 向いていること | 伏せ太郎との違い |
| --- | --- | --- |
| Photoshop 等で手動マスク | 確実に隠したい、細かいデザイン調整 | 検出候補から始められるので、矩形を一から引く手間が減る |
| クラウドの AI マスク系サービス | 高精度・大量処理 | 画像がサーバーに送られる前提になりがち。伏せ太郎はブラウザ内完結を優先 |
| スマホアプリ | 日常の写真編集 | インストールや権限が不要。URL だけで試せる |

伏せ太郎は **「とりあえず今すぐ、手元のブラウザで、送らずにマスクしたい」** とき向けに寄せています。検出精度は画像品質や文字条件に依存するため、**公開前の最終確認は利用者側でお願いしています**。

## 作った背景

きっかけは、技術記事や発表資料用にスクショを用意するときに、毎回同じ手間がかかることでした。

- 画面キャプチャにメールアドレスや氏名が写り込む
- 黒塗りの範囲調整に時間がかかり、記事公開が遅れる
- クラウドに画像を上げるのは、社内画面や未公開 UI の素材では心理的ハードルが高い

「ブラウザだけで、サーバーに送らず、顔と文字の両方をまとめて扱えたら楽なのに」と思い、個人開発で [伏せ太郎](https://fusely-app.pages.dev/) を作りました。

OSS として [GitHub で公開](https://github.com/illionillion/privacy-masking-app) しており、改善提案やバグ報告は Issue、質問・議論は Discussions でも受け付けています。

## 技術メモ

実装の概要だけまとめます。詳細はリポジトリの README を参照してください。

:::details 技術スタック・デプロイ・注意事項

### 技術スタック（概要）

- **フロント**: Next.js（TypeScript）
- **処理**: ブラウザ上で顔検出・OCR・マスキング（JavaScript）
- **配信**: 静的 export を `docs/` に出力し、Cloudflare Pages で公開

### デプロイの流れ

[README](https://github.com/illionillion/privacy-masking-app) では次のように運用しています。

- `next.config.ts` で `output: "export"` を指定し、本番ビルド時は静的ファイルを `docs/` に出力
- `main` への push をトリガーに GitHub Actions が `pnpm build` を実行し、生成された `docs/` をリポジトリへコミット
- Cloudflare Pages が `docs/` を公開ディレクトリとして配信

### ローカル開発

```bash
pnpm install
pnpm dev
```

`http://localhost:3000` で起動します。Node.js のバージョンはリポジトリの `.nvmrc` を参照してください。

### 注意事項

- 検出精度は画像の解像度・コントラスト・フォントなどに依存します
- 機密性の高い素材を扱う場合は、組織の運用ルールも併せて整備してください
- 画像本体はサーバーに送りませんが、初回のモデル取得やページ表示など、ブラウザからの通信が発生する場合があります

:::
